Notes on the Telia F1 I have open. Vantiva board GCNT-X, firmware 23.1.b.0448-7241017-20260223134332.

`findings/` is the writeups. `scripts/` is the tooling. Browser UI harvest: [`docs/f1-artifact-grabber.md`](docs/f1-artifact-grabber.md) (Tampermonkey userscript in `scripts/f1-grab-artifacts.user.js`). Packet captures go in `artifacts/captures/`. `./scripts/wan-capture.sh <iface>` takes a mirror capture and prints any Telia host, `.rbi`, or TLS name it sees. `./scripts/lcm-probe.sh` checks the LCM manifest. `./scripts/report.sh` rebuilds `findings/latest.md`. Script languages and password-change gates: [`scripts/TOOLING.md`](scripts/TOOLING.md).

Write the sha256 next to an image if you keep one. Don't commit the image.

Same day: first active BOOTP reply test executed (`scripts/f1-bootp-reply.ps1`) — reply accepted and used, TFTP timed out (no server), explicit device reset, normal boot resumed next cycle; see [BOOT-P LAN addendum](findings/f1-bootp-lan-2026-10-13.md). Next: `scripts/f1-tftp-serve-test.ps1` (new, **untested**) serves one small non-firmware file to exercise the loader's file-handling path.
