**2026-11-06 Flash volumes:** `findings/f1-flash-volumes-2026-11-06.md`. SSH root copied `loader`, `dri`, both `bootfs` FITs, both `rootfs` volumes, and the whole 512 MiB NAND (`mtd0`).
